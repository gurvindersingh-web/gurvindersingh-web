## Featured Project

### [WiFi Deauthentication Attack Defender & Analyser](https://github.com/gurvindersingh-web/Wifi-deauth-analyser-ai)

AI-powered 802.11 deauthentication attack detection system.

| Layer | Details |
|---|---|
| **Detection** | 7-signal heuristic engine with EMA-based adaptive baselines flags deauth floods in real time |
| **AI** | NVIDIA NIM classifies suspicious traffic patterns |
| **API** | FastAPI — REST + WebSocket endpoints |
| **Dashboard** | React 18 live monitoring UI |
| **Deploy** | Docker Compose with `NET_ADMIN` / `NET_RAW` capabilities |
| **Alerting** | n8n Cloud via Cloudflare Tunnel, from local capture box to the internet |
